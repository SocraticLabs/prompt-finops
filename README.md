# Prompt FinOps V1

A Next.js application for analyzing and optimizing LLM API costs through tokenization analysis and cost modeling.

## Features

- **Tokenization Analysis**: Analyze text using different tokenizers (GPT-4, GPT-3, Codex, GPT-2)
- **Cost Calculator**: Calculate and compare costs across major LLM providers (OpenAI, Anthropic, Google)
- **Token Efficiency Metrics**: Track compression ratios, unique token usage, and processing performance
- **Cost Visualization**: Interactive charts comparing model costs and provider pricing
- **Context Window Utilization**: Monitor token usage against model limits
- **Multi-Timeframe Projections**: Calculate costs across hourly, daily, weekly, monthly, and yearly timeframes
